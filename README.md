# TrueClip

A better clipboard.

## Dependencies

- Rust 1.92 or newer ([install with rustup](https://rustup.rs/))
- Windows MSVC toolchain, Visual Studio **Desktop development with C++** workload, and Windows SDK

## Run

```powershell
cargo run --locked
```

Build the release app:

```powershell
cargo build --release --locked
```
